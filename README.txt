چالش هوش - پروژه اندروید
طراحی و توسعه: مرتضی بحرینی

این یک پروژه Android Studio است که بازی HTML را داخل WebView اجرا می‌کند.
برای ساخت APK:
1. ZIP را استخراج کنید.
2. Android Studio را باز و پوشه ChallangeHoosh را Open کنید.
3. منتظر Sync شدن Gradle بمانید.
4. از منوی Build > Build APK(s) استفاده کنید.
5. APK معمولاً در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

پیش‌نیاز: Android Studio و JDK سازگار، اتصال اینترنت برای دریافت Gradle.
این محیط در این گفتگو Android SDK/Gradle build ندارد؛ بنابراین APK باینری ساخته نشده، اما پروژه آماده build ارائه شده است.
